# Task Tracker

A tiny, dependency-free task tracker used as the example project in
DVCS's tutorial and demo script (see ../../../TUTORIAL.md and
../../../scripts/demo.sh). Not a real product — just enough substance
(multiple files, a real feature branch, a real merge, a real conflict) to
make the git-workflow demo mean something.

## Files

- `index.html` — page structure and the task list markup
- `style.css` — layout and color
- `app.js` — add/complete/remove task logic, persisted to `localStorage`
